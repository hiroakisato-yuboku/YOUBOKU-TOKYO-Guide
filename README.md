# YOUBOKU TOKYO Guide

YOUBOKU TOKYO is a work-style brand that supports diverse and flexible ways of working.  
The brand offers thoughtfully designed products, including its signature self-standing gadget pouch, Days Pouch, to help people organize their workspace while expressing their individuality.
